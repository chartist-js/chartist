Dark mode (new in v2): the same hues, except e, g and h, which disappear on Ink. They're lifted to #9C8E88, #4D7EF2 and #A748CA, so every series clears 3:1. Light mode is byte-identical to $ct-series-colors.

Known limits, documented rather than changed: a/b (red vs grapefruit) are close for everyone, and c yellow is faint on light paper. Docs recommend labels or the accessible theme for more than 3 series.
