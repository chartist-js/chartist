LineChart

classstable

Draws line, area and scatter charts. Each series becomes a <g class="ct-series"> with a path, optional area and one element per point.

signature
new LineChart(
  query: string | Element,
  data: LineChartData,
  options?: LineChartOptions,
  responsiveOptions?: ResponsiveOptions<LineChartOptions>
)

Events

Subscribe with chart.on(name, handler). The draw event fires for every SVG element and is the hook for custom animations and plugins.

EventPayloadWhen
draw{ type, element, index, series, … }For each line, point, area, grid line and label as it's created.
created{ svg, options, axisX, axisY, … }After the whole chart has been drawn.
data{ type, data }When data is set initially or updated, before drawing.
optionsChanged{ previousOptions, currentOptions }When a responsive breakpoint switches the active options.
example · fade points in one by one
chart.on('draw', (ctx) => {
  if (ctx.type === 'point') {
    ctx.element.attr({ style: `animation-delay: ${ctx.index * 80}ms` });
  }
});

Methods
