Getting started

Your first chart in about two minutes. No build step, no bundler, no framework. Just an HTML file and a browser.

Works without a bundler. Chartist v2 ships as a native ES module, so a <script type="module"> is all you need. Using npm instead? Skip to Using npm.

1

Add the stylesheet and a container

The stylesheet holds the default look: series colors, grid, labels. The container is any element; Chartist fills it with an SVG.

index.html
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/npm/chartist/dist/index.css">

<div id="chart" class="ct-chart"></div>
2

Import Chartist as a module

Import only the chart types you use. Each one is a class you create with a container, data and options.

index.html
<script type="module">
  import { LineChart } from 'https://cdn.jsdelivr.net/npm/chartist/dist/index.js';
</script>
3

Draw your first chart

Labels go along the x-axis, each array in series becomes one line. Try changing a number below.

Using npm and a bundler

Same API, installed from npm. Works with Vite, webpack, Rollup, esbuild and Astro out of the box.

$ npm install chartist
main.ts
import { BarChart } from 'chartist';
import 'chartist/dist/index.css';

new BarChart('#chart', { labels, series }, { stackBars: true });

Make it yours with CSS

There's no theme option. Charts are SVG with predictable classes, so you style them the way you style everything else. Custom properties cover the common cases:

#chart {
  --ct-series-a: #0544d3;     /* first series */
  --ct-line-width: 4px;
  --ct-grid-dasharray: none;
}

Upgrading from v1.5? Your charts keep their exact colors. v2's classic palette is identical; the new accessible palette is opt-in. See Migrating from v1.
