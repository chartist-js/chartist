v2 · TypeScript, ESM, CSS-first

Simple charts, dressed in CSS.

Chartist draws clean, responsive SVG charts and leaves the styling to you. No canvas, no dependencies, no theme engine. Just classes and custom properties.

$ npm install chartist

import { LineChart } from 'chartist';
import 'chartist/dist/index.css';
 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/chartist/dist/index.css">
<script type="module">
  import { LineChart } from 'https://cdn.jsdelivr.net/npm/chartist/dist/index.js';
  new LineChart('#chart', { series: [[1, 3, 2, 5]] });
</script>

Responsive sugar topping

Pass a few media queries with option overrides, and Chartist rearranges labels, ticks and spacing as the container changes. Drag the slider to try it.

responsiveOptionsactive: {{respRule}}
[
  ['screen and (min-width: 640px)', {
    axisX: { labelInterpolationFnc: month }  // "Jan"
  }],
  ['screen and (min-width: 420px)', {
    axisX: { labelInterpolationFnc: initial } // "J"
  }],
  ['screen', {
    axisX: { labelInterpolationFnc: quarters } // "Q1"
  }]
]

Animations, in plain CSS

Lines draw, bars grow, donuts fill. It's all CSS on SVG, and it switches itself off for people who prefer reduced motion.
