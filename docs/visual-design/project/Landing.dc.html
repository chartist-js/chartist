What makes it worth it

The things people pick Chartist for, each with a tiny live demo.

Style it with CSS

Plain SVG with predictable classes. Colors, lines, grid and labels are custom properties, scoped to a page, a container or one chart.

--ct-series-a

Responsive, two ways

Breakpoints by the window, or by the chart's own container. Same conditions you already write in CSS.

responsive: [
  ['(width < 600px)', { … }],
  [container('(width < 400px)'), { … }]
]
container() is experimental · needs a polyfill today

Composed charts

Bars and lines in one chart, with left and right y-axes, each scaled to its own series.

Renders anywhere SVG does

Labels are real SVG text, wrapped to fit. Render on the server, and charts survive PDFs, email and image converters.

const svg = renderToString(
  toScene('line', data, options)
);

Bend it to your will

Every chart flows through an open pipeline. Each step has a hook, and every single element passes through events you can change, replace or decorate. Plugins are just functions that use the same hooks.

Same data, three tiny plugins
lollipop.js
// a plugin is a function that receives the chart
export const lollipop = () => (chart) =>
  chart.on('draw', (el) => {
    if (el.type !== 'bar') return;
    el.attr({ style: 'stroke-width: 3px' });
    el.parent.elem('circle', { cx: el.x2, cy: el.y2, r: 6 });
  });

Responsive sugar topping

Grab the corner and squeeze the chart. Labels, ticks and spacing rearrange themselves, driven by the same conditions you'd write in CSS.

    axisX: { labelInterpolationFnc: month }   // "Jan"
  }],

    axisX: { labelInterpolationFnc: initial } // "J"
