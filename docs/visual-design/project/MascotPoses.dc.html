A gentleman for every occasion

<Mascot pose="…" /> renders each of these from one SVG. Hover any of them: the hat tips and the moustache wiggles.

The live chart slot

Like 2014, the board is a real nested <svg>. Any Chartist chart can render into #chart-slot (viewBox units, 200 × 136). The board color stays light in dark mode so charts read like paper.

Animatable parts: .m-hat-tip, .m-eyes (blink), .m-stache (wiggle), .m-tap (pointing arm), .m-confetti. All are disabled by prefers-reduced-motion.

Avatar & small sizes

≤ 32 px

Above 40 px use the face avatar (GitHub org, Discord, npm). Below that, switch to the logomark: his head cropped tight under the brim, like the 2014 icon.
