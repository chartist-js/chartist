Where Chartist shines

Small bundles, plain SVG, styling with the CSS you already write, ESM straight from a CDN with no build step, and a permissive license.

Where others offer more

More chart types out of the box, and built-in interactivity like tooltips, zoom and panning. If you need a full dashboard toolkit, they're great choices.

How we measured

Bundle size: a single line chart built with each library's recommended import, minified and gzipped with the same bundler settings. Feature rows come from each library's own documentation. Numbers are regenerated at build time; last run [DATE]. Spotted something out of date? Open an issue.
