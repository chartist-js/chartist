07 · Design tokens

One stylesheet for the site, the guy and the charts

Three layers of CSS custom properties. The docs site, the mascot SVG and the library's default theme all read from the same file, so they can never drift apart.

1 · Primitives

Raw values with names. Never used directly by components.

--p-waistcoat-500: #C8102E;
--p-cream-100: #FBF6EE;
--p-ink-800: #2B2426;
--p-mustard-400: #F4C63D;
2 · Semantic (themed)

Meaning, not color. .cx is light, .cx.dark remaps the same names.

--brand: var(--p-waistcoat-500);
--bg: var(--p-cream-100);
--ink: var(--p-ink-800);
--ct-series-a: #d70206;
3 · Components

Site components, mascot parts and .ct-* chart classes consume semantic tokens only.

.btn.primary { background: var(--brand) }
.ct-series-a { --ct-color: var(--ct-series-a) }
.ct-line { stroke: var(--ct-color) }
.m-vest { fill: var(--m-vest) }
Same SVG, different tokens

No JavaScript option changes here: only the wrapper's class swaps, and the CSS custom properties do the rest.
