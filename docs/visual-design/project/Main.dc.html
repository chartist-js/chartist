Chartist v2

Bring back the soul of 0.x, made for today. The same well-dressed gentleman, the same chart on his easel, retailored for SVG, CSS custom properties and dark mode.

01

Same gentleman, new tailoring. The 3/4 profile with the angled face, top hat, handlebar moustache, red waistcoat and easel all stay. So does the hay fork in his left hand.

02

The board chart stays. His board still plots the chart of the 2014 site, labelled just 1st, 2nd, 3rd.

03

Warm palette, grown up. Cream #EADBC4 becomes Paper, red becomes Waistcoat, yellow becomes the Mustard logo tile, warm gray #453D3F becomes Ink. Chart colors stay exactly as in 1.5, plus an opt-in color-blind-safe theme.

04

Style with CSS, control with JS — the brand too. Every color, the mascot included, is a custom property. One token file themes the site, the guy and the default chart.
